### 46장 async/await

### async/await란?

- 프로미스를 기반으로 하는 **비동기 처리 문법의 문법적 설탕(syntactic sugar)**
- 프로미스를 `.then()`으로 연결하는 것보다 **가독성이 좋고 동기식 코드처럼 작성 가능**

### async 함수

- `async` 키워드를 함수 앞에 붙이면 **반드시 프로미스를 반환함**
- 명시적으로 `return` 값을 작성하면, 이는 자동으로 `Promise.resolve(value)`로 감싸짐
- 내부에서 `await` 키워드를 사용할 수 있음

```jsx
async function foo() {
  return 1; // Promise.resolve(1)과 같음
}
```

### await 키워드

- `await`는 **프로미스가 이행될 때까지 대기**하고, 완료되면 결과 값을 반환
- `await`는 `async` 함수 내에서만 사용 가능
- `await` 이후의 코드는 **프로미스가 처리된 후에 실행됨**

```jsx
async function fetchData() {
  const response = await fetch(url);
  const data = await response.json();
  return data;
}
```

### async/await와 동기적 코드 스타일

- 코드가 마치 **순차적 동기 코드처럼 보이도록 작성 가능**
- `try...catch` 블록을 사용하여 **예외 처리**를 간결하게 할 수 있음

```jsx
async function getUser() {
  try {
    const user = await fetchUser();
    console.log(user);
  } catch (error) {
    console.error(error);
  }
}
```

### 에러 처리

- `await` 뒤에 있는 프로미스가 **reject**되면 예외가 발생하고 `catch` 블록으로 이동함
- `try...catch`를 사용하지 않으면 예외는 전파되어 `async` 함수가 반환하는 프로미스가 reject 상태가 됨

### async/await과 병렬 처리

- `await`를 연속으로 사용하면 각 프로미스가 **직렬로 처리됨**
- 병렬로 처리하려면 `Promise.all`을 함께 사용

```jsx
async function loadData() {
  const [a, b] = await Promise.all([fetchA(), fetchB()]);
  return [a, b];
}
```

### 주의 사항

- `await`는 **비동기 함수 실행 흐름을 잠깐 멈추는 것**처럼 보이지만, 실제로는 **이벤트 루프에 의해 다음 태스크로 넘어감**
- 블로킹은 발생하지 않지만, `await` 사용 시에는 함수의 흐름이 일시 중단되므로 **성능 고려 필요**
