### 45장 프로미스

### 프로미스란?

- 자바스크립트 비동기 처리를 위한 객체
- 미래에 완료될 수도, 실패할 수도 있는 작업을 나타냄
- 콜백 함수 기반 비동기 처리의 **가독성 문제**, **콜백 헬** 등을 해결하기 위해 도입됨

### 프로미스의 3가지 상태

- `pending` (대기): 이행도 거부도 되지 않은 초기 상태
- `fulfilled` (이행): 작업이 성공적으로 완료된 상태, `resolve()` 호출
- `rejected` (거부): 작업이 실패한 상태, `reject()` 호출

### 프로미스 생성

- `new Promise((resolve, reject) => {...})` 형태
- executor 함수는 프로미스가 생성되자마자 동기적으로 실행됨

```jsx
const promise = new Promise((resolve, reject) => {
  if (success) {
    resolve("성공");
  } else {
    reject("실패");
  }
});
```

### `then`, `catch`, `finally`

- `then(onFulfilled, onRejected)`: 성공/실패 시 각각의 콜백 실행
- `catch(onRejected)`: 실패 시만 콜백 실행
- `finally()`: 성공/실패 여부와 무관하게 항상 실행됨

```jsx
promise
  .then((result) => console.log(result))
  .catch((error) => console.error(error))
  .finally(() => console.log("무조건 실행"));
```

### 프로미스 체이닝

- `then`은 새로운 프로미스를 반환
- 연속된 비동기 작업을 순차적으로 연결 가능

```jsx
fetchData()
  .then((data) => processData(data))
  .then((result) => displayResult(result))
  .catch((error) => handleError(error));
```

### 프로미스의 예외 처리

- `then` 내부에서 오류가 발생하면 `catch`에서 처리됨
- `try...catch` 대신 `catch` 메서드를 통해 예외를 핸들링

### 프로미스 정적 메서드

- `Promise.resolve(value)`: 즉시 이행되는 프로미스 생성
- `Promise.reject(error)`: 즉시 거부되는 프로미스 생성
- `Promise.all([p1, p2, ...])`: 모든 프로미스가 이행되면 결과 배열 반환. 하나라도 reject되면 전체가 reject됨
- `Promise.race([p1, p2, ...])`: 가장 먼저 끝나는 프로미스의 결과를 반환
- `Promise.allSettled([p1, p2, ...])`: 모두 종료되면 각각의 상태와 결과를 배열로 반환

### 콜백 패턴 vs 프로미스

- 콜백 패턴은 중첩과 가독성 문제 → 콜백 헬 발생
- 프로미스는 체이닝과 명확한 예외 처리가 가능하여 유지보수에 유리
